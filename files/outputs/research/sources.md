## 逐来源证据与局限

### S1 Anthropic 原文
- 简述：Anthropic 称 GLM-5.3 能端到端开发漏洞利用且防护易被绕过；见 F1–F3。
- 定位：首个章节前有导语及图1（发现汇总）；正文分端到端利用能力、安全防护、影响三部分。F1–F3 定位见 fact-check 表。
- 局限：厂商自测；对 CAISI 的转引不采用。

### S3 ExploitBench 论文
- 定位：摘要页。
- 证据：该基准不把“触发崩溃”视为利用成功，而是把利用过程拆成 16 个可验证能力标志的分层阶梯（从覆盖、崩溃到任意读写、控制流劫持、任意代码执行），以确定性判定器验证；实例化于 41 个 V8 漏洞；设基础、增强（自适应指导）、消融三组实验。
- 局限：仅读摘要，未核实全文方法细节。分层能力分数与 F1 口径不同，不可混用；F1 分母的构成未从 S3 核实，列为待核实。

### S4 Hugging Face 模型卡
- 直接核实：页面属 zai-org 组织，标注开放权重，并有“文件与版本”标签页，可公开获取权重；页面另列 HuggingChat 及多个第三方推理服务入口。
- 未核实/未知：许可证页面只显示一个自定义许可标签，具体条款未读取，许可内容标“未知”；模型卡正文未写发布日期，标“未知”（不以论文日期或仓库信息推断）。
- 局限：模型卡中的各类基准分为厂商自报，口径与 S1 不同，本项目不采用。

### S5 Z.ai 官方文档
- 直接核实：Z.ai 官方提供 GLM-5.3 的 API 接入，文档列出 API 模型标识、上下文与最大输出长度、推理强度档位，并兼容多种调用协议；文档称其为 Z.ai 最新旗舰模型（厂商说法）。
- 未见：本页未显示价格、发布日期、开放权重或许可说明、安全/使用政策；F3 的价格依据未在 S5 核实。

### S6 Google/Mandiant 漏洞利用时间（TTE）分析
- 定位：正文 TTE 定义与 2023 年统计段、方法说明段、建议段。
- 证据：TTE 指漏洞在补丁发布之前或之后被利用的平均时间（零日计为补丁前、N 日计为补丁后）；样本为 2023 年披露且被在野利用的 138 个漏洞；剔除 15 个统计异常值后 123 个平均 5 天，未剔除为 47 天；2023 年零日约占七成。
- 局限：作者说明以“首次被报道的利用”计时，若日期模糊取最晚可能日期，实际利用时间可能更早。这是相对补丁发布的利用时间，不是“所有漏洞披露后平均几天被利用”。数据早于 GLM-5.3，不能直接推论 AI 的影响。
- 防守建议：加快修补、按利用难度与价值排序、网络分段与访问控制、假设利用会发生。

### S9 拒绝方向论文
- 定位：摘要页。
- 证据：在 13 个最高 72B 参数的开源对话模型中，拒绝行为由激活空间中的单一方向介导；擦除该方向会削弱拒绝，加强则增强拒绝；作者据此指出当前安全微调较脆弱。
- 局限：结论仅限其 2024 年实验的模型，不含 GLM-5.3；不能用 F2 的行为结果证明该机制同样适用于 GLM-5.3。S1 直接链接本论文作为 abliteration（拒绝削弱技术）出处，引用关系明确；具体实现及机制对 GLM-5.3 的适用性未核实。本清单不描述任何具体操作方法。

### S10 GTIG 对抗性 AI 报告
- 定位：本地开放权重模型案例段、关于自主攻击管线的评估段、各案例后的处置说明。
- 证据：GTIG 记录一个威胁行为者在被入侵的基础设施中部署本地开放权重模型，以规避商业 AI 的 API 监控；GTIG 称尚未观察到在野的完全自主攻击管线；Google 对涉及滥用的资产采取禁用等处置。
- 局限：报告不涉及 GLM-5.3 或智谱，不能据此指称 GLM-5.3 已被滥用；案例以 Google 自身可见范围为主，存在可见性偏差。
